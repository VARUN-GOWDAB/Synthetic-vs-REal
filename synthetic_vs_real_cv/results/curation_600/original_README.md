# Real dataset directory

This directory is reserved for the real-world industrial-safety images and labels used in the final study.

Requirements:

- keep the original image data under a versioned folder
- store annotation files in a consistent format such as COCO JSON or YOLO TXT
- preserve metadata such as source video, camera ID, and capture conditions
- ensure the final test set remains completely untouched during model selection and training

The final dataset choice should be made only after checking licensing, class availability, and domain relevance.
