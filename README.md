# Synthetic vs Real Research Workspace

This workspace serves as the project directory for the study titled:

"Evaluating the Effectiveness of Synthetic Data for Real-World Object Detection"

The implementation scaffold is located in the `synthetic_vs_real_cv/` subfolder and includes:

- research design and research report
- critical review and revised methodology
- experiment configuration
- reproducible project structure
- minimal end-to-end prototype pipeline

## Quick start

1. Review the project design in `synthetic_vs_real_cv/README.md`.
2. Inspect the experiment configuration in `synthetic_vs_real_cv/configs/experiment_config.yaml`.
3. Run the minimal prototype:

```powershell
cd "c:\Users\SIC\Desktop\Synthetic-vs-REal\synthetic_vs_real_cv"
& "c:/Users/SIC/Desktop/Synthetic-vs-REal/.venv/Scripts/python.exe" -m src.prototype.prototype_pipeline
```

## Important note

This repository documents the research study and provides a working prototype, but it does not claim completed real-world results without the final dataset and model execution.
